# COSMOS SANDBOX 100LY

Interactive 3D Symplectic N-Body & 100-Light-Year Universe Simulator — single-page web app with zero external dependencies.

## Features
- **Interactive 3D Views**: Solar System, TRAPPIST-1, 55 Cancri, Alpha Centauri, and 100-LY 54-Star Neighborhood (drag to orbit, scroll to zoom).
- **Physics Engine**: 4th-Order Yoshida Symplectic N-Body integrator with optional 1st Post-Newtonian (1PN) General Relativity correction and live energy-drift readout.
- **Live Controls**: Real-time Primary Mass, Orbital Velocity, and Time-Step (`dt`) sliders, plus Play/Pause/Reset.
- **Bilingual UI**: Instant English / 繁體中文 toggle.
- **Hong Kong Public Astronomy Board**: Quick guide to Hong Kong Space Museum, Sai Kung Astropark, and local dark-sky spots.
